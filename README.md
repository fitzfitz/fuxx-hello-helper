# Hello Helper

A tiny test plugin for [fuxx](https://github.com/fitzfitz/fuxx-cli): a `fuxx-hello` command and a `FUXX_HELLO` variable in fuxx's zsh terminals.

To install: in fuxx, open Settings → Plugins, paste `github.com/fitzfitz/fuxx-hello-helper` and press Install. fuxx warns you that it runs a program on your Mac; this one only prints a line.
